# 📹 Sample Traffic Videos Directory

Place sample `.mp4` or `.avi` traffic video clips in this folder for testing with the Gradio demo (`demo/app.py`) or command line scripts.

### Recommended Clip Sources:
1. **Vietnamese CCTV Traffic footage**: Intersections, roundabouts, high-density motorcycle traffic.
2. **CADP Dataset clips**: Fixed camera accident sequences.
3. **DoTA Anomaly dataset clips**: Dashcam / Egocentric recordings.

You can also run synthetic test generation or download sample clips using `python scripts/download_datasets.py`.
